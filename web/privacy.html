隐私政策

适用于 WordCloudArt Chrome 扩展 · 最后更新：2026 年 8 月 8 日

WordCloudArt 不收集、不存储、不传输任何个人数据。扩展本身不发起任何网络请求。

页面文本

只有在你点击 Generate 按钮时，扩展才会向当前标签页注入一次脚本，读取你选中的文本， 或自动识别出的正文。这段文本只存在于浏览器内存中，用于统计词频和绘制词云， 关闭侧边栏后即消失。它不会被写入磁盘，也不会被发送到任何服务器。

生成的图片

词云图在你的设备上通过 Canvas 绘制完成。只有当你主动点击「下载」或「复制」时， 图片才会离开扩展 —— 保存到你自己的下载目录，或放进你自己的剪贴板。

设置项

模板、配色、词数上限和排除词等界面偏好保存在 chrome.storage.local， 仅存于本机。这些设置不参与 Chrome 同步，也不会离开你的电脑。

网络请求

扩展不发起任何网络请求：没有统计分析，没有远程代码，没有第三方服务， 没有账号系统，没有广告或追踪。所有代码都随扩展包一起发布，可在 GitHub 仓库 中审阅。

权限说明

sidePanel 在 Chrome 侧边栏中显示扩展界面。
scripting 在你点击 Generate 时，向当前标签页注入一次取词脚本。不点击就不注入。
tabs 读取当前标签页的标题和网址，用于界面提示和给下载的文件命名。
contextMenus 提供右键菜单入口。
storage 在本机记住你的界面设置。
网站访问权限 你可能在任何网页上想生成词云，因此取词脚本需要能注入到任意站点。 扩展只在你明确点击 Generate 时读取页面，且从不把内容发往任何地方。

儿童隐私

本扩展不面向儿童设计，也不会有意收集任何年龄段用户的数据 —— 因为它不收集任何数据。

政策变更

如果本政策发生变化，本页顶部的更新日期会随之修改。涉及数据处理方式的实质性变更， 会在扩展的版本说明中一并注明。

联系方式

有任何疑问，可通过 GitHub Issues 联系我们。

Privacy Policy

For the WordCloudArt Chrome extension · Last updated: 8 August 2026

WordCloudArt collects, stores, and transmits no personal data. The extension makes no network requests at all.

Page text

A script is injected into the active tab only when you click Generate, and only to read the text you selected or the main article of the page. That text stays in browser memory, is used to count words and draw the cloud, and is gone when you close the panel. It is never written to disk and never sent to a server.

Generated images

The word cloud is drawn on your own device with Canvas. It leaves the extension only when you choose to download it or copy it, in which case it goes to your own downloads folder or your own clipboard.

Settings

Interface preferences — template, palette, word limit, exclusion list — are kept in chrome.storage.local on your device. They are not synced and do not leave your computer.

Network requests

The extension makes none. No analytics, no remote code, no third-party services, no accounts, no ads, no tracking. All code ships inside the extension package and can be reviewed in the GitHub repository.

Permissions

sidePanel Shows the extension's interface in Chrome's side panel.
scripting Injects a one-off text-reading script when you click Generate, and not before.
tabs Reads the active tab's title and URL to label the panel and name the downloaded file.
contextMenus Adds a right-click entry for opening the panel.
storage Remembers your interface settings locally.
Host access You may want a word cloud on any page you are reading, so the text-reading script must be injectable on any site. The extension reads a page only when you click Generate, and never sends what it reads anywhere.

Children's privacy

This extension is not directed at children and does not knowingly collect data from users of any age, because it collects no data at all.

Changes to this policy

If this policy changes, the date at the top of this page will change with it. Any material change to how data is handled will also be noted in the extension's release notes.
